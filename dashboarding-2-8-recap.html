Design before you build

Map user questions to click paths, then sketch the layout

User story framework

  • Chain the users' questions top-down to map their click paths
  • Target: 3 to 5 clicks maximum per insight
  • More than 5 clicks signals that a redesign is needed

Draw before you build

  • Always sketch the dashboard layout first
  • Get sign-off on the design before implementing
  • It prevents the “I changed my mind” later

Tableau core concepts

From sheet to workbook: one sheet is one graph, no exceptions

Vocabulary hierarchy

Workbookthe whole file
Storya sequence
Dashboard
Sheet1 graph

Sheets and dashboards

  • Text, images and filters are placed in the dashboard, not the sheet
  • A single sheet can appear in several dashboards
  • Filters are created in the sheet first, then usable in the dashboard

Columns, rows and markers

  • Columns / Rows = x-axis and y-axis
  • Markers control how data is displayed: color, size, label, text
  • Drag fields onto a marker to configure it
One sheet, one graph: everything else is assembled in the dashboard

Connecting data and saving

Extract mode and the TWBX format for every Excel or CSV project

Two connection modes

  • Live: real-time sync, but slow
  • Extract: snapshot optimized for Tableau, to refresh when the source data updates
  • Excel / CSV: a live connection brings no benefit, always use Extract
Teacher's experience
6 min → 2 s

Daily refresh of a database of 11M rows, after switching from Live to Extract.

Two save formats

  • TWB: graph only, no data (confidential data + live database connection)
  • TWBX: graph + data, required for submission so the professor can open the file
Group project: Extract mode + TWBX, or points are deducted

Building the dashboard

Create the graphs, assemble the “Lego”, add interactivity

Graph creation

  • Double-click fields to add them to the sheet
  • Use Show Me to change the chart type
  • Log scale: double-click an axis → Scale → Logarithm (skewed data like population or GDP)
  • Default aggregation is Sum: switch to Average for GDP and life expectancy

Dashboard assembly

  • Set the size to Automatic, not Fixed
  • Drag sheets onto the canvas and position them carefully (top / bottom / left / right)
  • Set KPI sheets to Entire View to fill their container
  • Add text and images from the Objects panel (bottom left)

Interactivity

  • Select a sheet on the dashboard → Use as Filter
  • Clicking it then filters all the other graphs
  • To configure individually for each sheet
Build sheet by sheet, then assemble and connect them with Use as Filter

Workbook organization (graded)

Three mandatory housekeeping steps for the group project

Naming convention

  • Numbered sheets, e.g. 1.1 KPI Population, 1.2 KPI Life Expectancy
  • First digit = target dashboard number, which helps manage 100+ sheets
  • About 7 graphs per dashboard at most, to avoid cognitive overload
  • Dashboard name, e.g. 1.GDP-Analysis
  • Graph titles renamed to user-friendly labels (double-click the title)

The three mandatory steps

  • 1 · Rename all sheets
    with the numbered convention.
  • 2 · Color-code
    sheets in blue, dashboards in red (Shift + right-click → Color).
  • 3 · Hide all sheets behind the dashboard
    right-click the dashboard → Hide All Sheets.
Rename, color-code, hide: three steps that are graded
